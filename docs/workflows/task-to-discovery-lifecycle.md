# Task-to-Discovery lifecycle

This page is retained for link compatibility. The canonical owner is the
[Scientific lifecycle](../concepts/scientific-lifecycle/index.md).

In particular, the canonical lifecycle uses eligible feasible leaf
`SCIENTIFIC` Tasks and **at-most-one** cardinalities. A parent Task produces no
Hypothesis and no Discovery, and typed non-completion may end an investigation
without a Discovery. Use the
[Contract and cardinality reference](../reference/contract-and-cardinality-reference.md)
for the concise lookup.
