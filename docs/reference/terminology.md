# Terminology

This page defines canonical terms for the conceptual foundation. Capitalization
identifies named objects and records; lower-case phrases identify concepts or
acts. See the [object catalog](object-catalog.md) for classification and
authority lookup.

| Term | Canonical meaning | Do not confuse with | Owner |
| --- | --- | --- | --- |
| active context | The bounded, purpose-specific, validity-aware selection available to a current operation. | the full history, chat transcript, or all relevant text | [Context](../concepts/context/index.md#active-context-mental-model) |
| admission | The application-authority act that validates a contract and makes the authorized state durable. | proposal, evaluation, governance approval, or model output | [Evidence admission](../concepts/scientific-lifecycle/evidence-and-analysis-frames.md#evidence-admission) |
| `AnalysisFrame` | Non-FCO provenance identifying the exact data view used by analytical work. | DataProfile, raw dataset, Evidence, or generated table | [AnalysisFrame](../concepts/scientific-lifecycle/evidence-and-analysis-frames.md#analysisframe) |
| application authority | The boundary that owns identity, admission, persistence, transactions, lifecycle transitions, validity propagation, and operational safety. | scientific authorship or governance judgment | [Planning and scientific state](../concepts/research-state/planning-and-scientific-state.md#protected-evaluation-and-outcomes) |
| `Assumption` | FCO planning constraint that may guide planning but is excluded from protected evaluation. | Evidence, verified fact, or scientific premise | [Assumptions guide planning only](../concepts/research-state/planning-and-scientific-state.md#assumptions-guide-planning-only) |
| authoritative state | State admitted or transitioned by the authority designated for that exact contract. | plausible text, a specialist result, or a proposal | [Research-state foundation](../concepts/research-state/index.md#how-layers-interact) |
| canonical contract | A finite typed agreement that fixes meaning, required fields, authority, lineage, and validation for a boundary. | an informal prompt or semantically similar payload | [Structural canonicalization](../concepts/research-state/identity-scope-and-lineage.md#structural-canonicalization-preserves-meaning) |
| `Discovery` | FCO semantic-graph claim bound to Evidence, explicit scope, validity basis, governance, and admission. | Evidence, DiscoveryProposal, summary, insight, or final answer | [Discovery admission](../concepts/scientific-lifecycle/discovery-governance.md#discovery-admission) |
| `DiscoveryProposal` | Non-FCO scientific proposal produced by protected evaluation and eligible for governance. | an admitted Discovery or GovernanceDecision | [DiscoveryProposal is not Discovery](../concepts/scientific-lifecycle/discovery-governance.md#discoveryproposal-is-not-discovery) |
| `Evidence` | Immutable FCO semantic-graph record of an admitted observation, bound to scientific lineage and provenance. | raw tool output, interpretation, or Discovery | [Evidence traceability](../concepts/scientific-lifecycle/evidence-and-analysis-frames.md#evidence-traceability) |
| `EvidenceRequest` | Non-FCO investigation record specifying an Evidence obligation or a bounded request for further observation. | Evidence itself or an unrestricted instruction to analyze data | [EvidenceRequest and DataWorkOrder](../concepts/scientific-lifecycle/evidence-and-analysis-frames.md#evidencerequest-and-dataworkorder) |
| First-Class Object | A domain concept with durable identity and a first-class role in research state. | semantic graph node; the properties are independent | [The eight FCOs](../concepts/research-state/objects-and-state-layers.md#the-eight-first-class-objects) |
| `GeneratedView` | Non-FCO derived presentation such as an answer, report, table, or synthesis. | Discovery or authoritative scientific state | [Generated views and session membership](../concepts/research-state/objects-and-state-layers.md#generated-views-and-session-membership) |
| governance | The authority process that may approve, reject, or hold an eligible proposal and request correction, Evidence, or review. | scientific evaluation, revision of scientific wording, or admission | [Governance decisions](../concepts/scientific-lifecycle/discovery-governance.md#governance-decisions) |
| historical truth-to-record | The faithful record of what was observed, admitted, or decided at a particular time. | current eligibility or current scientific authority | [Historical truth and current authority](../concepts/research-state/identity-scope-and-lineage.md#historical-truth-and-current-authority) |
| `Hypothesis` | FCO semantic-graph scientific commitment for an eligible feasible leaf `SCIENTIFIC` Task. | Assumption, Task description, result, or Discovery | [Scientific initiation](../concepts/scientific-lifecycle/scientific-authority.md#scientific-initiation) |
| immutable | Admitted content cannot be rewritten in place; changed meaning requires a new record and traceable lifecycle relation. | permanent current validity or inability to attach lifecycle state | [DataProfile identity](../concepts/research-state/identity-scope-and-lineage.md#dataprofile-identity-is-immutable) |
| `InvestigationPlan` | Non-FCO record of how an eligible scientific investigation is intended to proceed. | PlanRevision, which versions the broader Task DAG | [InvestigationPlan and InvestigationProtocol](../concepts/scientific-lifecycle/scientific-authority.md#investigationplan-and-investigationprotocol) |
| `InvestigationProtocol` | Non-FCO operational scientific contract for testing a Hypothesis and satisfying Evidence obligations. | Planner-authored Task, execution attempt, or result | [InvestigationPlan and InvestigationProtocol](../concepts/scientific-lifecycle/scientific-authority.md#investigationplan-and-investigationprotocol) |
| lineage | Typed relationships connecting scope, data state, scientific commitment, provenance, Evidence, outcome, and claim. | chronological adjacency or textual similarity | [High-level scientific lineage](../concepts/research-state/identity-scope-and-lineage.md#high-level-scientific-lineage) |
| non-Discovery outcome | Typed ending that records why an investigation did not yield an eligible admitted Discovery. | missing data, discarded history, or a weakly worded Discovery | [Typed non-Discovery endings](../concepts/scientific-lifecycle/protected-evaluation.md#typed-non-discovery-endings) |
| `Objective` | FCO semantic-graph root scope defining what an investigation seeks to establish. | Workspace, question string, PlanRevision, or global project singleton | [Objective establishes scope](../concepts/research-state/planning-and-scientific-state.md#objective-establishes-scope) |
| `PlanRevision` | Immutable non-FCO snapshot of one complete plan for one Objective, including Task DAG membership and coordination metadata but no configurable stopping-condition or replan-trigger policy. | Task identity, workflow-lifecycle events, InvestigationProtocol stopping semantics, DataWorkOrder stopping semantics, or an in-place edit to approved Tasks | [Task and PlanRevision](../concepts/research-state/planning-and-scientific-state.md#task-is-work-planrevision-is-a-plan) |
| protected evaluation | Authority-bounded scientific evaluation over a closed, type-safe set of admitted inputs. | a peer Evaluator agent, governance, or open-ended retrieval | [Protected evaluation](../concepts/scientific-lifecycle/protected-evaluation.md) |
| research state | The governed durable account of scope, work, data, scientific commitments, observations, outcomes, authority, validity, provenance, and active context. | conversation history, generic memory, or vector retrieval | [Research-state foundation](../concepts/research-state/index.md) |
| scientific authority | Authority to determine scientific feasibility, operationalization, evaluation, or proposal content within a typed contract. | application persistence authority or governance approval | [Planning and scientific state](../concepts/research-state/planning-and-scientific-state.md) |
| `ScientificInvestigationRun` | Non-FCO lifecycle record for one governed scientific investigation associated with an eligible Task. | ExecutionRun, Hypothesis, or Discovery | [Major non-FCO families](../concepts/research-state/objects-and-state-layers.md#major-non-fco-state-families) |
| `SessionFrame` | FCO recording structured research-session membership and active Objective/DataProfile selectors for continuity. | operation-specific context, conversation history, generic summary, evidential support, GeneratedView, or semantic-graph node | [SessionFrame](../concepts/context/session-frame.md) |
| structural canonicalization | Deterministic typed validation, ordering, serialization, version binding, duplicate rejection, and digesting without semantic inference. | synonym resolution, unit inference, semantic normalization, or compatibility judgment | [Structural canonicalization](../concepts/research-state/identity-scope-and-lineage.md#structural-canonicalization-preserves-meaning) |
| semantic Knowledge Graph | The canonical epistemic graph containing exactly Objective, Hypothesis, Evidence, and Discovery. | all durable state, all FCOs, or a generic vector store | [Semantic graph membership](../concepts/research-state/objects-and-state-layers.md#semantic-graph-membership) |
| `Task` | FCO durable semantic work unit of kind `DATA`, `SCIENTIFIC`, `GRAPH`, or `SYNTHESIS`. | PlanRevision, scientific knowledge, or a semantic-graph node | [Task and PlanRevision](../concepts/research-state/planning-and-scientific-state.md#task-is-work-planrevision-is-a-plan) |
| validity | The governed basis for deciding whether recorded state remains eligible for a particular current use. | truth-to-record, popularity, confidence wording, retrieval relevance, or an unscoped boolean | [Validity](../concepts/validity/index.md) |
| `Workspace` | The resolved user research project root: a non-FCO container in which multiple Objectives and workspace-scoped resources may be organized. Conventional user data is under `data/`; CogniEDA-private state is under `.cognieda/`. | the product repository, an FCO, an Objective, or one semantic Knowledge Graph node | [Workspace ownership](../development/workspace-layout.md) |

The canonical object set and state-family classification are summarized in the
[object catalog](object-catalog.md).
