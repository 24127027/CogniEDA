# Active context and retrieval

This page is retained for link compatibility. CogniEDA is validity-preserving
research-state infrastructure, not a memory system.

Canonical ownership now belongs to:

- [Context](../concepts/context/index.md) for the active-context mental model
  and context-mode overview;
- [SessionFrame](../concepts/context/session-frame.md) for the active-context
  FCO;
- [Context type safety](../concepts/context/context-type-safety.md) for
  mode-specific eligibility and exclusions;
- [Retrieval strategy](../concepts/context/retrieval-strategy.md) for
  eligibility-first retrieval and Graph Miner;
- [Continuity and resume](../concepts/context/continuity-and-resume.md) for
  restart-safe state reconstruction;
- [System overview](system-overview.md) for semantic Knowledge Graph and total
  persistence boundaries.

The semantic Knowledge Graph contains exactly Objective, Hypothesis, Evidence,
and Discovery. Other durable workflow, context, provenance, validity,
presentation, and recovery state remains outside that graph.
