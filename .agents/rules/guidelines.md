# CogniEDA session guidelines

This is the repository session-bootstrap instruction. Read the root
[`AGENTS.md`](../../AGENTS.md) completely before acting; it owns the detailed
canonical guardrails. This file creates no separate architecture or concept
authority.

For every repository task:

1. Verify the active branch, fetched remote baseline, ancestry, and worktree
   before relying on a prior report or status claim.
2. Treat source and tests as authoritative for current behavior, canonical
   owner pages and design decisions as authoritative for target architecture,
   and report any difference without normalizing one into the other.
3. Preserve the requested write scope. Do not turn an audit or documentation
   task into runtime, schema, test, migration, dependency, or configuration
   changes.
4. Fail closed when identity, lineage, scope, authorization, contract version,
   or current-use eligibility cannot be established.
5. Run checks proportional to the changed boundary and report the exact
   commands, results, protected invariant, and unresolved risk.
